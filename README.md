# Tijdkompas — prijsdata
Automatisch bijgewerkt door `.github/workflows/prijzen.yml` op `main`.
- `prijzen.json.gz`: prijzen per supermarkt, met normale prijs + sinds-datum bij aanbiedingen
- `staat.json.gz`: prijsgeschiedenis (laatste 35 dagen) waarmee aanbiedingen worden herkend
Bron: [Checkjebon.nl](https://github.com/supermarkt/checkjebon) (MIT-licentie).
